# poppy-agent-tester

Demo-tier standalone app. It plays the **personal agent** from the Personal Agent Protocol (Poppy, Draft 0.3, https://personalagentprotocol.org/docs/introduction): read a Company's `poppy.json`, sign in to a **real PingFederate** with a URL as the client id (CIMD) and PKCE, then call the Company API with a signed `Poppy-Session`. Real PingFederate only (owner decision 2026-10-28; exception to rules 1 and 18: the SE build is an explainer with an example run).

- Run: `./scripts/run.sh` (http://localhost:5450). Test: `npm test` (server `node --test test/*.test.js`, web vitest, repo `scripts/*.test.mjs`). Preflight: `npm run doctor`. Reset: `npm run reset`. Talk track: `npm run talk-track`. Content pack: `npm run content-pack`.
- Live run needs: a PingFederate CIMD policy for `${PAT_AGENT_BASE_URL}/client.json` whose token manager takes `client_id` from the request (docs/setup.md), the agent served over https (`PAT_TLS_CERT`/`PAT_TLS_KEY`, `PAT_BIND`, `PAT_AGENT_HOST`), and a Company serving poppy.json.
- Core: `server/src/jose.js` (ES256, P-256 via `createECDH`), `poppy.js` (delegation + Poppy-Session signer), `oauth.js` (PKCE, `private_key_jwt`, header typ `client-authentication+jwt`), `discover.js` (typed-origin discovery), `app.js` (API), `sessions.js` (per-workspace state), `netguard.js` (typed hosts only). Story data `story.js` with `{{castBrand}}`-style tokens filled by `cast.js` (3 verticals); a test fails on an undefined token. Diagram `server/diagrams/poppy-flow.json` (diagram-studio/1).
- API: `GET /api/info|story|sample|diagram|state|health`, `POST /api/discover|authorize|call|reset`, plus `GET /client.json`, `/jwks.json`, `/cb`. Workspace id in `X-Workspace`.
- Rules that bite: loopback bind unless `PAT_BIND`; same-origin writes; outbound only to the two typed hosts (a permit lasts 30 s and is renewed before each call); only `.example`/`.invalid` hosts in shipped text; no `crypto.generateKeyPair('ec')` (use `createECDH`); ports 5450-5499; PF wants assertion typ `client-authentication+jwt` and `aud` = issuer; PF caches CIMD clients 5+ minutes; the agent key persists in `.data` for that reason.
- Status: proven against a local PingFederate and a local Company on 2026-10-30 (token client_id = the agent URL, 200 from `/poppy/api/v1/me`). `protected_resources` in the issuer metadata is shown as a warn check (no PingFederate setting known). Not exercised: refresh, revocation, device grant, DPoP, MCP. Catalog id D100 is provisional.
- Hosted guard fails closed: MODE unset/`live` is live, any other MODE is hosted; PAT_HOSTED anything but ''/0/false is hosted. The public agent name (`PAT_AGENT_HOST`) serves only GET `/client.json`, `/jwks.json`, `/cb`.
